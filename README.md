# data.overheid.nl (data-overheid-nl)

data.overheid.nl is a national government open-data portal for Netherlands running **CKAN**, exposing a standardized catalog API over ~20,386 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/data-overheid-nl/refs/heads/main/apis.yml)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=data-overheid-nl-api-evangelist&utm_content=repo)

## Type
- **kind:** government  ·  **software:** CKAN  ·  **version:** 2.8.12

## API
- **data.overheid.nl CKAN Action API** — base `https://data.overheid.nl/data/api/3/action`. [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://data.overheid.nl/data)
- Live endpoint verified: `https://data.overheid.nl/data/api/3/action/status_show` · ~20,386 datasets
